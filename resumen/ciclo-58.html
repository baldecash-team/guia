🖥️ Comando previo al reinicio (verificar configuración)

Correr antes de reiniciar Apache en WS para validar que la configuración esté correcta y evitar dejar el servicio caído.

# 1) Validar sintaxis de la configuración
sudo apachectl configtest        # equivalente: sudo httpd -t  /  sudo apache2ctl -t

# 2) Revisar virtual hosts y config efectiva
sudo apachectl -S

# 3) Solo si configtest = "Syntax OK", reiniciar
sudo systemctl restart apache2   # o reinicio en caliente: sudo apachectl graceful
